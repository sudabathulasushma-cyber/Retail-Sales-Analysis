# Retail Sales Analysis Dashboard

## About the Project

This project analyzes retail sales data using Python and presents the results in an interactive dashboard built with Streamlit.

## Features

* Total revenue, units sold, and sales record metrics
* Revenue analysis by product
* Revenue analysis by category
* Monthly revenue trends
* Interactive product and category filters
* Business insights based on selected data
* Sales records table

## Technologies Used

* Python
* Pandas
* Streamlit
* Matplotlib

## Project Structure

* `app.py` — Python sales analysis
* `dashboard.py` — Interactive Streamlit dashboard
* `sales.csv` — Sample retail sales dataset
* `README.md` — Project documentation

## How to Run

1. Install Python.

2. Install the required libraries:

   `python -m pip install pandas streamlit matplotlib`

3. Open a terminal in the project folder.

4. Run the dashboard:

   `python -m streamlit run dashboard.py`

## Dataset

The project currently uses a small sample dataset created for learning and demonstration.

## Learning Outcomes

* Reading CSV files using Pandas
* Calculating revenue from quantity and unit price
* Grouping sales by product, category, and month
* Creating charts and an interactive dashboard
* Presenting business insights from data
